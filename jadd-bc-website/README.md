# Jadd BC Webサイト

日本人の福音宣教のためのキリスト教放送宣教ミニストリー「Jadd BC」の公式Webサイトリポジトリです。

## 含まれているファイル構成
- `index.html`: ホームページ本体（デザインCSS組み込み済み）
- `images/`: ロゴやQRコード画像
  - `logo.png`: Jadd BC ロゴ
  - `line-qr.png`: 公式LINE QRコード
  - `youtube-qr.jpg`: 公式YouTube QRコード
  - `worship-qr.jpg`: Jadd Worship QRコード
  - `jadd-bible.jpg`: Jadd Bible イラスト画像

## GitHub Pages での公開手順
1. 本ZIPファイルを解凍します。
2. GitHubのリポジトリに `index.html` および `images` フォルダの中身をアップロードしてコミットします。
3. リポジトリの **Settings** > **Pages** で Branch を `main`、Folder を `/ (root)` に設定して保存（Save）します。
4. 数分後にWebサイトURLが発行され、全世界へ公開されます。
